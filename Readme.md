# Smart Decision Assistant

## Project Overview

Smart Decision Assistant is a recommendation-based project developed using Core Java, HTML, and CSS.

This project helps users make better decisions in different categories by considering their requirements and providing a suitable recommendation.

## Categories

* Laptop Recommendation
* Mobile Recommendation
* Career Recommendation
* Travel Recommendation

## Features

* Budget-based filtering
* Requirement-based recommendation
* Score calculation
* Best option selection
* Simple and user-friendly interface
* Separate recommendation logic for each category

## Technologies Used

* Core Java
* HTML5
* CSS3
* OOP Concepts
* ArrayList
* Scanner
* Conditional Statements
* Loops

## How to Run

### Java Recommendation Engine

Open PowerShell and navigate to the Core-Java folder:

```powershell
cd C:\Users\Dell\Desktop\SmartDecisionAssistant\Core-Java
```

Compile the required Java files.

Example:

```powershell
javac Laptop.java LaptopTest.java DecisionEngine.java
```

Run the recommendation engine:

```powershell
java DecisionEngine
```

Similarly, Mobile, Career and Travel recommendation engines can be compiled and executed.

### HTML Website

Open the following file in a web browser:

```text
HTML/index.html
```

The website provides navigation to Laptop, Mobile, Career and Travel recommendation pages.

## Recommendation Logic

The Core Java modules:

1. Accept user requirements.
2. Filter suitable options.
3. Calculate a score.
4. Compare the scores.
5. Select the option with the highest score.
6. Display the recommended option.
